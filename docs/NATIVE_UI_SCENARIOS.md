# macOS 原生 UI 场景复验

## 运行离屏场景

从待测 worktree 的根目录运行。线程只构建 Rust macOS 二进制和调试夹具，沿用同用户主机锁、checkout 锁及独立 `.voiceport/target-native-ui`，Cargo 使用锁定依赖和离线模式。夹具从当前进程的未展示窗口渲染实际 AppKit 控件，不启动已安装 App，也不捕获桌面像素。快捷键、来源、文本、结果和投递目标由夹具提供。复制接收器在内存中。

```sh
python3 -I -B scripts/verify_native_ui.py \
  --expect-head EXPECTED_FULL_COMMIT \
  --expect-inputs FROZEN_PRODUCT_INVENTORY_SHA256 \
  --baseline /absolute/private/old-run/report.json
```

`--expect-inputs` 用于核对已冻结的未提交候选，`--baseline` 用于对照已通过的旧版。两个参数均可省略。旧版只有五个快捷面板场景时，用同一工具在旧源码上运行 `--suite legacy`，保留运行目录。工具本身可进入旧版的产品输入清单，旧版 Rust 源码应保持与指定提交一致。

| 场景 | 可观察结果 |
| --- | --- |
| 就绪、长标题、未配置 | 原生状态、快捷键及添加入口可见。展开后截断长标签，完整表述留在辅助功能属性。键盘跳过禁用来源，末项得焦时滚入视口。 |
| 转写忙态 | 状态与快捷键保持独立显示，配置操作不可用。 |
| 不确定投递、查看正文 | 260 点的合成屏幕条件下仍能到达「查看本次文字」与「复制」。待确认和重复复制分支使用内存接收器。 |
| 最近听写 | 合成 Controller 完成两次转写，延迟回执保留原条目，旧条目可从当前结果独立查询及复制。候选用固定日期渲染，旧版使用测试执行时的日期。 |
| 最终结果、编辑副本 | 原生听写页显示 Controller 最终文字，编辑副本和复制回调保留原结果及历史。 |

扩展夹具请求 `Prohibited`，启动日志 `native-ui-activation` 记录 setter 返回值、实际策略、目标策略及应用活动状态。只有 `activationPolicy()` 实际为 `Prohibited`（`2`）、应用非活跃且无 key/main window 时才继续建窗。每帧渲染前后复核策略、活动状态、实际 `NSView.window`、窗口未展示且非 key/main、应用无 key/main window，以及本地 first responder 不变。离屏计时记录首次创建夹具控件至首帧位图，以及 41 个合成来源下从刷新忙态到位图的两条单样本。两条均在 PNG 编码和写盘前结束。使用相同机器及冻结版本复跑时仍须将发行版冷启动、用户点击到可操作、阻塞期间 IPC、隐藏时渲染和转写阶段各自测量。

## 读回证据

每次在打印的 `.voiceport/evidence/native-ui.*` 新目录写入 `report.json`、输入清单、逐项 stdout/stderr、截图和 `deck.md`。报告记录 HEAD、对应 tree、候选产品输入摘要、工具链、实际执行二进制 SHA-256、命令、退出和进程组清理。输入和执行件在运行边界复核。图像记录包含 PNG 尺寸、文件大小和 SHA-256。`passed` 表示本轮执行和证据一致性检查通过。打开 `deck.md` 核对文字、截断、视口、控件状态及旧版画面，PNG 对照标记用于定位变化。历史日期、系统外观和像素密度会影响文件摘要。

新增或重做工作台页面时，以现有观察点给对应场景提供同样的合成状态。页面有可脱离展示的生产构建入口时，将原生根视图挂入本进程持有的未展示窗口再渲染。工作台壳集成后须另按冻结输入复验导航、页面焦点顺序、下载进度和错误恢复。真实菜单栏点击与 popover 合成、跨应用焦点、浮层位置和闪烁留给协调者安排的隔离 Aqua 会话。需要正焦点基线时使用现有 [原生浮层焦点入口](DICTATION_STATUS_OVERLAY.md#原生焦点验收)。
