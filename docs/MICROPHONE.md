# macOS 麦克风设置

在「设置 → 麦克风设置…」或菜单栏右键菜单打开。打开面板和「刷新设备」只读取系统设备，不开始录音。

- **跟随系统输入（默认）**：每次开始时使用 macOS 当时的默认输入；VoicePort 不会修改系统默认设备。
- **指定设备**：选择只保存在 VoicePort。设备按 CoreAudio 的稳定 UID 区分，同名设备可看名称后的短标识。拔插后即使系统临时设备编号变化，也以 UID 为准，不凭名称猜测。设备不可用或列表读取失败时，原偏好仍保留。
- **本轮实际输入**：只有 VoicePort 成功打开且从音频单元核对设备后才显示；如果已回退，显示实际设备及原因。偏好选中项不是当前输入的回执。

## 测试电平

空闲时点击「测试电平 · 10 秒」。须已允许麦克风权限；这个入口不弹出权限请求，也不会申请语音识别权限。它显示实际用于测试的设备和实时峰值（dBFS），区分已收到静音与尚无有效采样。音频只在内存中用于测量，不保存、不转写、不发送，也不操作目标应用。测试期间不启动听写；时间到、点击停止、关闭面板、退出或设备失效都会停止测试。

## 断连恢复

开始时找不到指定设备、无法读取设备列表或指定设备打不开时，会尝试经独立查询确认的系统输入。回退只影响这一次，不改写偏好。录音中，VoicePort 保留当前仍正常工作的输入；插入新设备不会打断本轮。当前输入因拔出、合盖或系统音频重新配置而失效时，本轮最多恢复一次：先关闭旧输入，再按指定 UID 和系统输入的顺序重新选路。只有实际打开并核对新设备后才显示恢复状态。恢复不重新启动转写，不重新计时；设备断开期间可能漏掉一小段声音。下一轮仍以保存的偏好重新选择。

没有可确认的输入、替代音频无法转换，或本轮再次断开时，VoicePort 停止本轮并提示重新录音，不提交不完整的音频进行最终转写。已出现在输入框的实时预览按现有投递规则保留或收敛，不代表本轮已经完成最终转写。
