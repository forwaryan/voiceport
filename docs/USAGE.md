# VoicePort 使用指南

本页介绍日常操作与排障。首次构建安装见 [README](../README.md#快速开始)，升级与签名见 [macOS 更新说明](MACOS_UPDATES.md)。

## 菜单栏与窗口

VoicePort 正常启动后常驻 macOS 右上角菜单栏，不占用 Dock，也不会自动录音。

- **左键点击图标**：展开快捷面板，查看当前来源并选择 ChatGPT、本地模型或已配置来源。
- **打开完整界面**：点击快捷面板顶部的图标，进入「听写」和「设置」页签。
- **右键点击图标**：打开结果与设置、复制最近文字、取消听写或退出。
- **关闭完整窗口**：应用继续常驻；点击菜单栏图标可再次进入。点击面板外部或按 Esc 收起快捷面板。

菜单栏图标会反映听写、转写或待处理状态，并适配深浅外观。悬停可查看当前来源、状态与快捷键。来源较多时可以滚动查看；不可用来源会显示原因。快捷面板与设置页的选中状态同步，选择会保存供下次使用。

正常重新打开应用时展示快捷面板；需要直接打开完整窗口，可显式执行：

```bash
open "$HOME/Applications/VoicePort.app" --args --show-window
```

### 菜单栏图标不可见

检查「系统设置 → 菜单栏」的显示开关。macOS 26 可能把终端启动的 VoicePort 归入启动应用的菜单栏组；此时 VoicePort 与启动应用（例如 Orca）的显示开关都需要允许。

菜单栏显示与辅助功能权限是两项独立设置，打开其中一项不会自动开启另一项。

## 快捷键与一次听写

默认快捷键是 **Control + Option + Space**：按一次开始，再按一次结束。也可以通过菜单栏开始或结束。单次录音最长 **3 分钟**。

1. 在菜单栏或设置中选好来源。
2. 回到目标应用，点好文字光标。
3. 按快捷键开始说话，再按一次停止，等待最终结果。
4. 检查输入框与结果面板，由你自行发送。

快捷键按下时会绑定目标应用。若随后 VoicePort 自己激活，程序先返回同一个目标应用并确认后再开始；若已经切换到其他应用、原应用退出或按键过期，本轮不会开始录音。

### 自定义快捷键

打开「设置 → 开始 / 停止快捷键」，可选择 **Control + Option + Space**、**Control + Shift + Space**，或点击「自定义…」后按下新的组合键并保存。

- 必须包含 Control、Option 或 Command，可再加 Shift。
- 支持字母、数字、常见符号、空格、方向键和 F1–F20；Esc、Tab、回车保留用于窗口操作。
- 按物理键位保存，字母和符号名称采用美式键位；切换输入法不会改变绑定。
- 录入期间暂停全局快捷键，不会开始听写；取消会恢复原键，注册冲突时保留原设置。

保存后立即生效，并在下次启动时恢复。菜单与面板提示同步更新；快捷键注册冲突会显示在设置中，可点击换一组。

## 来源管理与测试

在「设置 → 管理来源…」中添加、编辑、删除 HTTP 来源或导入插件；也可通过快捷面板的「添加转写方式…」进入。

**保存配置不会联网或执行插件。** HTTP 服务与 JSONL 插件不要求安装 Orca，也不读取 Codex 登录。HTTP Bearer key 与插件 secret 字段按来源独立存入 Keychain，不转发给其他来源。

录音、转写期间不能更改设置，刷新来源期间不能切换来源。本次录音与后续重试固定使用开始时的来源、配置、凭据关联和语言；之后更改设置不会重定向已有录音。来源缺失、禁用或失败时会报错，不自动切换。

### 来源测试

在设置中点击「测试各来源连通性与耗时…」，可逐项测试 ChatGPT、本地模型和自定义来源，也可一键测试全部，查看状态、样例总耗时与最近测试时间。

测试只在主动点击后运行，使用内置一秒静音样例；不启用麦克风、不投递文字、不切换当前来源，也不改已有听写结果。远程来源或外部程序可能联网并产生服务用量。静音测试用于连通性诊断，不能说明识别质量，也不能把不同来源的样例耗时视为语音识别性能基准。

接入细节见 [HTTP 与自定义来源](CUSTOM_SOURCES.md)、[JSONL 插件](TRANSCRIPTION_PLUGINS.md) 和 [本地模型](LOCAL_MODELS.md)。

## 权限准备

| 权限 | 使用范围 | 缺失时的处理 |
| --- | --- | --- |
| 麦克风 | 所有来源的录音 | 无法录音，先完成系统授权。 |
| 辅助功能 | 自动向目标应用输入 | 开启自动输入时会在录音前提示；也可关闭自动输入，仅转写到面板。 |
| 语音识别 | ChatGPT 来源的可选设备端预览 | 可继续停录后转写；本地模型与自定义来源不申请这项权限。 |

在设置页点击「未授权 · 设置」处理辅助功能授权。显式权限准备不会开始录音；本地与自定义来源的录音权限检查只检查麦克风。处理完系统提示后，回到目标应用，重新点好输入位置再开始。

开发包更新后，即使系统开关仍亮着，新包的实际权限也可能尚未生效。日常使用固定路径 `~/Applications/VoicePort.app`；签名连续性与重新授权说明见 [macOS 更新与权限身份](MACOS_UPDATES.md)。CLI 的 `doctor` 不申请或验证这些系统权限。

## 自动输入与恢复

应用会根据原输入位置的能力选择投递路径。可读写的普通字段可能更新本次听写拥有的文字范围；网页编辑区、Codex 与 Orca 聊天等路径可能在停录后分段键入最终文字；缺少标准文字接口的控件可能使用最终文字粘贴。具体路径、确认机制与实测范围见 [全局输入](INPUT_DELIVERY.md)。

自动输入不按回车，换行和控制字符会转换为空格；手动复制保留原文。焦点、文字、选区或用户操作变化时，会停止后续自动写入。单纯滚动不会取消，除非实际改变了输入焦点、文字或选区。

粘贴兼容路径使用剪贴板，最终文字留在剪贴板；期间进行其他复制、点击、编辑或切窗操作可能停止输入。密码、安全输入、明确只读或禁用的控件不会自动写入。输入事件或菜单提交成功只表示已发出请求，不能保证目标接收。

微信主窗口有专门的原生「编辑 → 粘贴」兼容路径；不满足窗口与菜单条件时保留面板结果。**向微信输入文字不等于使用微信语音识别**，微信识别来源尚未接入。

### 文字没有进入输入框

查看听写页的状态与原因。转写成功但输入失败时，会显示「转写完成 · 自动输入未完成」；复制结果后仍保留该提示。

1. 确认授权的是当前固定安装路径中的 VoicePort。
2. 回到目标输入框，重新点好光标；使用全局快捷键开始新一轮。
3. 听写期间避免切窗、移动光标或编辑同一段文字。
4. 若目标控件不兼容，从结果面板复制文字并手动粘贴。

普通字段的文字、选区与光标更新会逐步确认；部分延迟读回会显示 `[readback]`。辅助功能授权本身不能使未提供系统文字接口的控件变为可写。

### 取消与重试

取消后停止后续写入。普通字段中已经确认且未被用户改动的预览会尝试还原；未确认的写入可能保留已经生效的部分。**终端中已经输入的文字不会被撤回**，应用不会通过删除已有 CLI 内容来强行套用识别校正。

转写失败时，可在面板选择「重试这段录音」。不会自动重传，手动重试也不会把结果自动投递到新的输入位置。退出应用前，请先处理需要保留的文字或失败录音。

## ChatGPT 登录与网络

ChatGPT 来源读取以下位置的文件登录：

1. 非空 `CODEX_HOME` 下的 `auth.json`。
2. 未指定时使用 `~/.codex/auth.json`。

只支持自己的 ChatGPT 文件登录，不支持 API key 替代或应用内刷新。通过 Codex CLI 执行 `codex login` 准备登录；其他来源无需此登录。独立文件转写命令还可通过 `--auth PATH` 显式指定文件。

macOS App 的 ChatGPT 请求使用系统中显式配置的 HTTPS 代理。应用与 CLI 也支持 `VOICEPORT_HTTPS_PROXY` 指定 HTTP / HTTPS 代理；URL 不接受用户名或密码。HTTP 自定义来源有独立网络策略，不沿用 ChatGPT 的代理行为，详见 [自定义来源](CUSTOM_SOURCES.md)。

CLI `doctor` 只查询登录文件的元数据，不读取或验证凭据，也不联网。文件存在和诊断退出 0 都不代表登录有效；详细状态、文件转写格式与退出码见 [CLI 文档](CLI.md)。
