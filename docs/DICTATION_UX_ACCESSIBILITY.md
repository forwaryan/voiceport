# 听写界面无障碍验收清单（P0 / P1）

适用于菜单栏、快捷面板、首次设置、设备/模型、快捷键、来源、完整结果、词表与工作流等本轮改动。每个作者记录实际入口、固定输入、复验步骤、平台/外观、观察结果与未测范围。读到代码不等于实机确认。投递判定以[统一回执](INPUT_DELIVERY.md#统一回执与重复结果)为准。

| 检查项 | 可执行判据 |
| --- | --- |
| **状态不靠颜色** | 录音、转写、等待确认、已确认、已提交但未验证、结果不明、失败、停用都有对应可读文字，移除图标与颜色仍可区分。切换前后按钮文字、辅助功能名称和启用状态一致；不把提交或部分写入称为成功。 |
| **键盘可达** | 在允许的隔离窗口从首控件用 Tab / Shift–Tab 正反遍历，用 Space 或 Return 操作当前控件；记录实际跳过的隐藏/禁用项。正文可选中，不抢系统快捷键；编辑副本的 Tab 不形成焦点陷阱。使用 ⌘W 或界面明确提供的关闭键返回，对话框关闭复测焦点是否恢复。键盘导航依 macOS 的键盘导航设置；未获授权不要修改全局设置。 |
| **展开与恢复** | 展开/收起后分别验证诊断区是否进入/退出键路，焦点不滞留在隐藏内容。后台刷新不重建控件或移动编辑光标。复制反馈在本区域；投递不明时提示先检查原目标，不自动重投；重试转写与重发输入严格分开。 |
| **VoiceOver** | 导航读取控件角色、名称、当前值或状态、是否启用及展开状态；同名来源操作读出来仍能区分。文字标签是主信息，不把必需内容只放在 hover 提示里。动态图标不重复播报正文；每次状态更新不抢焦点。只能读原生 Accessibility 属性时，请区分“本地属性已验”和“实际 VoiceOver 播报未验”。 |
| **深浅色与对比** | 在 Aqua、Dark Aqua 和有条件时更高对比度下核对文字、焦点环、边框及选区。优先 AppKit 原生控件和语义颜色；普通正文目标至少 4.5:1，非文本关键边界/状态对比至少 3:1。不要把语义颜色的采用或计算机读取外观当成截图/实测对比结论。 |
| **长短与边界** | 使用合成空状态、长名称、重名、长正文、小窗口、成功/失败/取消/未完成状态，确认不遮挡带重要含义的文字，可滚动查看正文与诊断，缩略行可从明确的入口看到全信息。 |
| **隐私与副作用** | 数据去向区分设备、本机服务、远端服务、外部程序；定位/浏览不是执行，显式测试前写明合成样例及可能用量。测试不读取凭据或用户记录作为输入，不使用真实麦克风、登录、目标应用、系统剪贴板或权限请求，除非另有授权。 |

## P1：来源管理和完整结果

- **来源管理 → 我的来源：** 行区分启用、配置是否有效和进程内的独立样例测试结果。相同名称、但不同稳定 ID 的来源互不继承结果；编辑配置后不把旧快照的成功带到新配置。HTTP 只显示站点来源（scheme/host/port），不展示路径、查询或凭据；本机服务与外部程序可能另行转发。点击「查看测试…」关闭管理窗口并定位独立窗口中匹配的来源；不会测试、切换当前来源或提交。只有点击测试窗口中的测试动作才执行[既有独立测试](PLUGIN_UI_DESIGN.md#在-voiceport-中的落实)。样例回执及耗时不能证明识别质量。
- **听写 → 听写结果：** 正文可选择；「编辑副本」将当前最终文字作为临时可编辑副本，「复制原文 / 复制副本」只复制该版本，不投递，放弃副本后恢复原文。正文变化或新尝试接替正文时丢弃副本，不写历史，保留原有的正文与音频留存规则。若正文不属于最新 GUI 尝试，会标明；实时预览不是可编辑的最终文本。
- **听写 → 展开本轮诊断：** 按 GUI 的 `session` 与 `generation` 关联采集和耗时，几次投递操作不是字符进度。「已提交」不是目标接收确认，结果不明时请先检查原目标。重试只复用允许保留的录音，且重试结果不会自动重投。未封存/未观测的时长显示 `—`，不会沿用其他尝试的数据。

## 复验证据

记录固定基线/补丁、测试命令和退出码、实际输入或替身、通过/未测/失败项。先看实际操作再记录结论：独占 AppKit 控件的 key-view 和 AX 属性断言，只覆盖本进程中可观测的关系；VoiceOver 播报、全局快捷键、实际权限及目标投递须另有授权和证据。未测项不能写成已通过。
