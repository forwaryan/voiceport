## 投递路径名不能当作接收回执（2026-11-23）

- **规则：** 投递路径或回执变更时，同一 PR 核对代码、行为文档、操作指南和离线 Skill 的描述。分别记录选路、事件提交和目标控件接收，不用前一环替后一环。
- **原因：** 微信兼容路径改用 `clipboard_final` 后，仓库 CLI 指南和离线排查流程仍把 `wechat_menu_paste` 当成当前路径。选路时就会写入 `input.method`，之后仍可能取消或失败。独立复核还发现，面板和 CLI 听写跳过[自动捕获](../crates/voiceport-macos/src/controller.rs)，所以 `status` 可能沿用前一轮投递的路径和失败阶段。
- **证据：** 执行基线 `91bc8d146cdee8a5b70200da89094dd081e0524b` 中，`git grep -n wechat_menu_paste 91bc8d1 -- docs/CLI.md skills/voiceport/references/` 同时显示两处过时说明和一处已正确标旧版的说明。[选路实现](../crates/voiceport-macos/src/delivery.rs)的 `Delivery::accept_capture` 在实际提交前设置 `clipboard_final`；[回执回归](../crates/voiceport-macos/tests/delivery_receipt.rs)的 `clipboard_submission_is_not_confirmation_and_uncertainty_cannot_retry` 区分提交与确认。历史[合成目标记录](INPUT_DELIVERY.md#验证范围)证明专用控件能收到文字，不证明真实微信聊天框接收。本次只纠正文档，不改变投递代码。

- **证据：** 设备候选的上一轮恢复夹具退出 `101`。修正自动语言输入后，精确冻结候选的设备恢复、电平和私有 IPC 三条检查均退出 `0`。按 [runner](../scripts/verification_run.py) 启动子进程时记录的 PID 查验各自进程组，均无剩余成员；对两把锁的 `lsof` 均退出 `1`，无持有者，随后完成交接。该报告覆盖设备候选定向复验。工作台正常导航、原生焦点和整批量化对照仍需各自的实际证据。

独立观察：1 次（2026-11-26）。

## 测试已连接超时时先确认请求已到达（2026-11-26）

- **规则：** 用可控测试时钟在真实夹具收到请求后触发超时。等待请求时同时观察被测调用是否提前完成，并为夹具保留独立的等待上限。
- **原因：** QQ adapter 的测试用例先启动 30 ms 截止，再等本地 socket 收到请求。如果输入在期限后才就绪，适配器已返回 `timeout`，夹具仍会等一个永远不会发送的请求。
- **证据：** [PR #68 首次失败](https://github.com/forwaryan/voiceport/actions/runs/45793507817/job/139818183843) 的 `qq-node` 在第 16 项通过后停住，600.264 秒超时。相同 Node 22.23.5 下，延迟合成输入 80 ms 复现了旧夹具等待；修正后同一反例通过，仍核对单条超时回执、实际 socket 关闭和无重连。远端当时的调度状态未采集。

独立观察：1 次（2026-11-26）。

## 抽取包结构检查后复跑既有拒绝用例（2026-11-27）

- **规则：** 调整打包与校验共用的检查时，用原打包入口复跑受影响的旧夹具，核对拒绝和诊断文本。
- **原因：** 提取 bundle 结构检查时，异常 helper 和主程序权限错误仍被拒绝，但已有调用方断言的错误信息被改写。首轮定向自检覆盖了新增的签名 ZIP 和参数边界，漏掉了两个既有的完整 bundle 用例。

## 归档目录权限与签名要求都要经过实际工具（2026-11-27）

- **规则：** 检查 ZIP 权限时覆盖目录记录在子项前后的两种顺序。修改内联签名要求时，用实际 `codesign` 验证匹配和不匹配，区分要求解析错误和签名身份被拒。
- **原因：** 临时目录的默认权限掩盖了 ZIP 中不可遍历的目录。原 ad-hoc 正例绕过了 preview 和 distribution 的内联要求，两条路径以文件参数形式传入了表达式。
- **证据：** [PR #80](https://github.com/forwaryan/voiceport/pull/80) 的独评在 `0a9a938a7b945d02525618b1d1da93d68bdde61f` 观察到不可遍历的 ZIP 目录仍通过，以及真实 `codesign` 无法解析两条验证路径的内联参数。回归分别覆盖原始目录权限与无凭据的实际签名要求判断。

独立观察：1 次（2026-11-27）。
